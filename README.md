# Open Odyssey landing page

這是從遊戲專案獨立出的 landing page 專案；目前採用版本是根目錄的 [A2](index.html)，其餘提案集中在 [設計原型總覽](prototypes.html)。

```bash
pnpm install
pnpm dev --host 127.0.0.1 --port 4174
```

開啟 `http://127.0.0.1:4174/`。驗證使用 `LANDING_PREVIEW_URL=http://127.0.0.1:4174/ pnpm test:ui`。

## A3：電影式開場與航海圖轉場

[A3 預覽](a3.html) 是 A2 的後續版本，保留首屏的船上視角、島嶼焦點與左右前景，但不再把島、船、海面各自切成不精準的圖層。主圖 `a3-hero-clean.png` 以提供的主視覺為編修目標，移除影像中的字標並保留完整場景；弧形 ODYSSEY 由 SVG 呈現，編修提示詞見 [a3-image-prompt.md](a3-image-prompt.md)。捲動時整體場景推近、文字退場，同一個固定舞台逐步浮現航海圖與引言，沒有複製海洋圖片接在首屏下方。直向比例改用 `a2-hero-mobile-clean.png`，但保留相同的捲動演出。

後續航海日誌、海域互動、同行者與港灣沿用 A2。A3 頁面位於 `a3.html`，新樣式與少量行為位於 `landing-a3.css`、`landing-a3.js`；A2 檔案與預覽保留供比較。以 Vite 啟動後開啟 `/a3.html`。瀏覽器驗證：`A3_PREVIEW_URL=http://127.0.0.1:4174/a3.html node verify-landing-a3.mjs`。

## A2：依回饋重新設計

[A2 預覽](a2.html) 保留 [A](a.html) 的船上視角、弧形 ODYSSEY 字標、左右副標語與無句號標題，品牌名稱為 Open Odyssey。桌面主視覺使用完整、無物件殘影的海天底圖，搭配同座標的獨立字標、島嶼與船首圖層；海面近景重用同一張底圖、在海平線下方漸進接管畫面，捲動時的推近幅度大於遠處島嶼，同時維持兩者在海平線貼合。細微的滑鼠視差只作用於船首前景，船層預留覆蓋範圍避免露邊。直向與手機畫面採較輕的單圖視差。首屏在固定舞台內、捲動過半後才緩慢漸變為 A3 的航海圖，再銜接紙本日誌、五海域劇場、航行者與港灣，不以另一張海景硬接首屏。

五片海的畫面根據使用者附圖，以內建 imagegen 各生成一張橫向無字素材，存為 a2-open.jpg、a2-storm.jpg、a2-siren.jpg、a2-calypso.jpg、a2-ithaca.jpg。圖像延伸方式與提示詞見 [a2-image-prompts.md](a2-image-prompts.md)。日誌以假名「小安」署名並提供三句可切換內容；同行者使用「怡君」。兩者都不顯示「示例」或玩家連線說明，也不宣稱即時連線。A2 仍是設計原型，點選日誌只更新本頁畫面，不送出或儲存內容。

A2 頁面與互動位於 `index.html`、`landing-a2.css`、`landing-a2.js`，`a2.html` 保留作舊網址相容入口，A 原版也保留。圖層由 `build-a2-hero-assets.cjs` 重建；素材來源、補景提示詞與遮罩處理見 [A2_PARALLAX_ASSETS.md](A2_PARALLAX_ASSETS.md)。獨立版本的啟航按鈕會在本頁導覽，正式串接遊戲時可將連結替換為遊戲的已發布網址。瀏覽器驗證涵蓋 1280×800、1440×900 等完整桌面視窗與手機尺寸。

這次交付包含三套各六區塊的視覺稿，以及三個可在本機操作的 HTML 設計原型。A 以大量捲動動畫及互動為主，B 與 C 用不同閱讀節奏和視覺語言重新設計，保留現有遊戲程式碼。

## A：動畫演出

選定 A 後，已依六張原稿重新製作可操作頁面。六段都使用從原稿移除文字及控制項後的海景，保留船帆、索具、島嶼、日誌紙張與夕陽構圖。文字與按鈕使用真正的 HTML，不把整張設計稿當成網頁。

敘事依序為啟航、日誌、海域、同行、歸返、開始航程。滿版畫面保留原稿不同的文字錨點，暗色漸層銜接相鄰海景，不再插入一般圖文欄位。捲動時背景與開場字標以不同速度移動。日誌按鈕開啟三個示例，選擇後更新紙上的文字和海象，不連接 AI、不保存輸入。五段海域支援點選與鍵盤操作、交疊淡出；「送一陣風」觸發短暫風線並回報訊息。

動畫以原生捲動、CSS 和 requestAnimationFrame 實作，沒有鎖住滾輪或改寫正常捲動。減少動態控制與系統偏好會停用視差、轉場、持續捲動提示及風線，功能仍可操作。手機使用直向裁切，日誌仍對齊實際紙張；標題保留有意義的斷行。

## B：航海手稿

把「今天」收進一本能回應人的書。以明亮紙色與墨藍保留書寫氣質，航海油畫成為跨頁內容而非滿版背景。章節標題與圖像採不同寬度，書頁留白負責閱讀層級，不堆疊卡片。

## C：海的座標

把「由你掌舵」轉成海洋海報。無襯線大字、鈷藍和粉筆白交替，海景以不等寬照片和大面積裁切呈現。珊瑚色標記操作，航線只是視覺導引，不把人生海域做成關卡或完成百分比。

## 產品邊界與交付限制

五段海域是心理狀態。同行者為模擬角色示例，未加入即時多人連線、假人數或真實使用者見證。伊薩卡由玩家自己定義與決定抵達。

產圖使用內建 imagegen，各區塊各一張橫向圖片。原始提示詞在 prompts.md；本次六張素材的編輯提示詞在 a-restoration-prompts.json。A 使用 a-scene-1.jpg 到 a-scene-6.jpg；塞壬之海與卡呂普索切換示例仍沿用 public/art 的既有素材。B、C 未更動。

A 的樣式與互動獨立於其他方向，檔案為 landing-a.css、landing-a.js。修改前頁面保存在 a-before-restore.html。啟航按鈕連向既有遊戲首頁，不自動建立航程。完整預覽請使用 Vite（pnpm dev --host 127.0.0.1 --port 4173），開啟 http://127.0.0.1:4173/design/landing-page-v2/a.html；Python 靜態伺服器只能預覽頁面，無法執行遊戲入口。

本次瀏覽器驗證執行 node design/landing-page-v2/verify-landing-a.mjs。範圍包含六段素材載入、視差、日誌、對話框 Esc 與焦點返回、五海域鍵盤選擇、送風、減少動態、390 / 768 / 1440 / 1672 寬度及遊戲入口載入，無瀏覽器錯誤。截圖存於 /tmp/Codex-screenshot-odyssey-restored-*.png。只驗證入口，不修改或全面測試 3D 遊戲。
